About This Project

Smart Parking Occupancy Analysis and Prediction System Using R

This is a beginner-friendly full-stack college project built to help a college, office, hospital, or small facility monitor parking occupancy and predict future parking demand.

Problem It Solves

Drivers waste time searching for available parking spaces, while parking managers lack a clear view of peak occupancy periods. This system analyzes parking data, shows the current status on a live dashboard, identifies peak hours and busy days, and predicts future occupancy using a statistical model built in R.

Technology Stack
  • Frontend: HTML, CSS, Bootstrap, JavaScript, Chart.js
  • Backend: Python (Flask)
  • Data Analysis / ML: R (dplyr, ggplot2, linear regression)
  • Database: SQLite
How It Works

Parking records are stored in an SQLite database. Flask serves the web pages and a small REST API. For deeper statistical analysis and prediction, Flask calls R scripts directly using Python's subprocess module — the R scripts read the same database, compute statistics, generate charts, and (for prediction) train a linear regression model on the fly.
